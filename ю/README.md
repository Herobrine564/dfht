# Учёт заявок — мастерская по ремонту

Простая десктопная программа для учёта заявок на ремонт техники (телефоны, планшеты и т.п.).

## Возможности

- Создание новой заявки (клиент, телефон, устройство, неисправность, цена).
- Просмотр списка заявок в таблице.
- Фильтр по статусам: «Все», «Принято», «В ремонте», «Готово», «Выдано».
- Смена статуса заявки.
- Редактирование заявки (телефон, цена, описание и т.д.).
- Удаление заявки.

## Как запустить

1. Убедитесь, что у вас установлен Python 3.8+ (проверьте командой `python --version` в терминале).
2. В папке с проектом откройте терминал.
3. Запустите программу:  
   ```bash
   python main.py
